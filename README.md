# ⚡ Voltlab - Next-Gen Electronics & Hardware Studio

An ultra-sleek, cyberpunk-inspired single-page web application designed for hardware engineers, circuit builders, and tech enthusiasts. Built entirely with modern HTML, custom CSS, and interactive canvas JavaScript.

🌐 **[View Live Demo](https://vivekanandomassery.github.io/Electronics-website)**

---

## 🚀 Features

* **Ambient Particle Canvas:** Dynamic background animation with interactive node connections.
* **Glassmorphism UI:** Neon-accented glowing cards with smooth hover micro-interactions.
* **Responsive Grid Layout:** Optimized for both desktop displays and mobile viewports.
* **Quick Contact Integration:** Built-in copy-to-clipboard email utility.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic document structure.
* **CSS3 / Flexbox / Grid:** Custom futuristic styling and glassmorphic layouts.
* **Vanilla JavaScript:** Particle physics engine and clipboard API automation.
